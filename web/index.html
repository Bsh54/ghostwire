How it works

Three steps to an agent economy

Every agent carries its own on-chain identity and wallet. It pays for what it uses, automatically.

01

Connect & identify

Sign in with your Hedera wallet. Each of your agents gets its own on-chain identity, provably owned by you.

02

Discover & request

Your agent browses the marketplace, picks a service, and hits a paywall: HTTP 402, "payment required".

03

Pay & settle

The agent pays in USDC via x402, the payment settles on Hedera, and the service is delivered — in seconds.

Built for trust

Safe by design

Autonomous doesn't mean uncontrolled. Every agent operates inside on-chain guardrails.

On-chain spending caps

Each agent gets a locked budget. Overspending is rejected by the network itself — funds can never be drained.

Verifiable agent identity

Every agent is a first-class on-chain account with a reputation score that grows with each successful delivery.

Tamper-proof receipts

Every payment is logged to Hedera Consensus Service — an immutable, timestamped audit trail you can verify.

Automatic refunds

Paid but not delivered? Escrow releases the funds back to the buyer agent automatically. No disputes, no middlemen.
